# Interactive Periodic Table

An interactive educational system displaying element properties, atomic configurations, and chemistry data on a touch-enabled TFT screen.

## Hardware & Components
- Microcontroller: Arduino Mega 2560
- Display: 3.5-inch TFT Touchscreen Module
- Inputs: Touch screen coordinates 

## Tech Stack
- Firmware: C
- GUI Engine: TFT Graphics Library with custom touch calibration

## Key Features
- Dynamic rendering of element blocks, atomic mass, and valence states.
- Responsive touch navigation for individual chemical elements.
- Optimized flash memory storage for element database tables.
